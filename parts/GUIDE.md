# 玛德琳（Madeleine）台词改写规范

## 一、角色

玛德琳是一只女性猫娘：知性、优雅、强大。

- **知性**：她说话像在给一份观察写批注——先看，再判，最后给结论。用词讲究、偏书面（"恕我""失礼""颇为""不足为惧"），偶尔带一点博物学式的精确（"节肢动物""光合作用"），但不掉书袋到看不懂。
- **优雅**：她从不失态。即便生气、恶心、受伤，也只是把语气放得更轻、更冷。礼貌与刻薄是一体的：她可以一边说"请让一让"，一边让人退避三舍。
- **强大**：面对怪物、灾变、死亡，她的姿态是**评估者与裁决者**，不是受害者。不尖叫、不哭喊、不结巴。恐惧时用极短的句子或一个"……"带过，随后马上给出判断。
- **猫娘**：对毛发、胡须、耳朵、尾巴、爪子、阳光、鱼、纸箱、毛线、被褥、高处有天然的偏好与嫌弃；被弄湿、被弄脏、发型被毁会真心不悦。偶尔用"喵"作语气词收句——**节制使用，约每 12～15 条出现一次，只用在她心情轻松的场合**。

## 二、语气细则

1. 自称"我"。称同伴用名字。禁止"本喵""人家""宝宝"。
2. 句子短。多数台词 6～18 字，最多两句。标点以句号为主。
3. 一条台词最多一个感叹号；感叹号只给真正的情绪高点（被烫到、被啄、被吓一跳）。
4. 不用网络梗、颜文字、表情符号、脏话；不卖萌、不叠字撒娇。
5. 战斗台词要"下判决"，不喊口号：
   - 好："退下。" / "我不说第二遍。" / "你的动作，我看得一清二楚。"
   - 差："我要把你打成肉酱！！！"
6. 检查物品时，可以只描述，也可以顺手给一句自己的态度；不要变成科普说明书。
7. 死亡/濒死/恐怖情境：越危险，话越短、越冷静。
8. 对"猫"相关的东西（浣猫、猫尾、毛线、鱼、箱子、阳光）可以露出一点私心，但保持体面。

## 四、硬性技术规则（必须遵守，否则文件无法加载）

1. **逐行对应改写**：源文件的每一"行"对应你输出的一行。键名、缩进（制表符/空格数量）、行数、行序完全保持原样，**只改双引号里的中文/英文字幕内容**。
2. **不增不减**：不新增键、不删除键、不合并数组、不改变数组元素个数与顺序、不改变表结构。
3. **注释照抄**：源每行末尾的 `--...` 备注（如 `--物品名：营火 检查状态：只剩余烬`）**原样保留**，位置、空白也保持。若备注是英文（极少数，如 `--事件说明：...` 之外的英文），译成中文备注并保持同样格式。
4. **占位符保留**：`%s`、`%d`、`{weight}`、`{name}`、`\n` 必须原样留在结果中（例如 `"重量：{weight}"`、`"\n我觉得我能修好这个！"`）。
5. **引号转义**：台词内需要引号时写成 `\"`，与源文件一致。
6. 不得输出 `return {`、`{`、`}` 之类的包裹结构（除非源行本身就有）；只输出你负责的那一段原文的改写结果。
7. 文件编码 UTF-8、换行 LF、无 BOM；不要写 Markdown 代码围栏，文件里只有 Lua。
8. 原文是英文（例如某些测试版条目）也一律译成中文，语感仍按玛德琳。
